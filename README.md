# 오늘 뭐 먹지?

메뉴를 추가하고 룰렛을 돌려 오늘 먹을 음식을 고르는 작은 웹 앱입니다.

## 실행
`index.html`을 브라우저에서 엽니다. 설치하거나 빌드할 필요가 없습니다.

메뉴 저장은 브라우저의 localStorage를 사용합니다. 로컬 파일의 저장 동작은 브라우저 설정에 따라 다를 수 있습니다. 저장이 제한되면 현재 창에서 계속 사용할 수 있지만 다시 열 때 변경 내용이 사라질 수 있습니다.

## 사용
1. 상단에서 메뉴 종류를 선택합니다.
2. **메뉴 돌리기**를 누르면 선택한 종류의 메뉴 하나를 추천합니다.
3. 하단에서 이름과 종류를 입력해 메뉴를 추가하거나 목록의 **삭제**를 누릅니다.

## 파일 구조
| 파일 | 역할 |
| --- | --- |
| index.html | 화면 구조 |
| style.css | 색상, 글꼴, 간격, 모바일 레이아웃 |
| app.js | 버튼 이벤트, 룰렛 그리기, 애니메이션, 저장 |
| logic.js | 메뉴 검증, 필터링, 회전 각도 계산 |
| PRD.md | 제품 목적과 기능 요구사항 |
| CLAUDE.md | AI 작업 지침 |
| .gitignore | Git에서 제외할 파일 목록 |
| README.md | 실행 및 사용 안내 |
| gemini-code-1793166006127.html | 수정하지 않은 기존 원본 (미완성) |

저장 데이터는 서버로 전송되지 않으며 브라우저 데이터를 지우면 삭제됩니다.
