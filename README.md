# 오늘 뭐 먹지?

메뉴를 추가하고 룰렛을 돌려 오늘 먹을 음식을 고르는 작은 웹 앱입니다.

## 실행
`index.html`을 브라우저에서 엽니다. 설치하거나 빌드할 필요가 없습니다.

메뉴 저장은 브라우저의 localStorage를 사용합니다. 로컬 파일의 저장 동작은 브라우저 설정에 따라 다를 수 있습니다. 저장이 제한되면 현재 창에서 계속 사용할 수 있지만 다시 열 때 변경 내용이 사라질 수 있습니다.

## 사용
1. 상단에서 메뉴 종류를 선택합니다.
2. **메뉴 돌리기**를 누르면 선택한 종류의 메뉴 하나를 추천합니다.
3. 하단에서 이름과 종류를 입력해 메뉴를 추가하거나 목록의 **삭제**를 누릅니다.

## 최근 30일 TOP 5
제목 아래, 종류 선택 버튼 위에 최근 30일 동안 많이 추천된 메뉴 5개와 횟수를 표시합니다. 최초 실행 시 하루 한 번씩 30일간 사용한 임시 기록 30개를 생성해 브라우저에 저장합니다. 초기 순위는 김치찌개 7회, 치킨 6회, 돈가스 5회, 초밥 4회, 파스타 3회입니다.

예시 기록은 화면에서 **예시 데이터 포함**으로 구분하고 예시/실제 횟수를 함께 표시합니다. 이후 룰렛이 끝날 때마다 실제 기록이 추가됩니다. 기록은 `lunchRecommendationHistory.v1`에 메뉴 목록과 별도로 저장하므로 새로고침 시 예시를 중복 생성하지 않습니다. 최근 30일을 벗어난 기록과 미래 기록은 순위에서 제외하며, 종류 필터와 관계없이 전체 메뉴를 집계합니다. 같은 횟수는 메뉴 이름순으로 표시합니다. 삭제한 메뉴의 과거 기록은 유지합니다.
